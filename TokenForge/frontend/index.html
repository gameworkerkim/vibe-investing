파이프라인

1. 전체 계획 프롬프트

목표를 넣으면 AI가 프로젝트를 목표→제약→산출물→단계→리스크로 분해하는 마스터 계획 프롬프트(영어)를 만들고 설명합니다.

→
2. 기억(Memory)

계획·세부 프롬프트·위키 스니펫을 저장합니다. (Cloudflare KV free tier / Upstash / 브라우저 localStorage 폴백)

→
3. 세부 프롬프트 작성

각 단계의 세부 프롬프트를 한국어·일본어·중국어 등 원하는 언어로 작성합니다.

→
4. DeepSeek로 영어 최적화

DeepSeek V4-Flash가 한국어/외국어 → 압축된 영어 프롬프트로 재작성 + 변경 이유/추천을 반환합니다.

→
5. 토큰 절약 예상도

Claude·ChatGPT 기준 원문 vs 최적화문 토큰 수·절약율·비용을 계산합니다 (휴리스틱 + ChatGPT는 tiktoken CDN 정밀모드).

→
6. 스킬로 만들기

계획 + 최적화된 프롬프트 번들을 SKILL.md(Claude·opencode 스킬 형식)로 내보냅니다.

전체 계획 프롬프트란?

코딩 에이전트(Claude Code·ChatGPT)에 단일 작업을 바로 시키기 전에, 먼저 “프로젝트 전체를 계획하라”고 지시하는 마스터 프롬프트를 쓰면 맥락 누락·반복 작업·토큰 낭비가 줄어듭니다. TokenForge는 이 전체 계획 프롬프트를 설명하고, 그 계획을 기억한 뒤, 단계별 세부 프롬프트를 한국어/외국어로 받아 영어로 최적화합니다.
