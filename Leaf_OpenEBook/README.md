## 핵심 아키텍처 결정

- 원본 이미지는 **private R2**에 격리, 인증된 사용자만 Workers 게이트로 서빙
- 워터마크는 **업로드 시 사전 합성(프리-컴포지트)** — Workers 무료 티어 CPU 10ms 제한 회피
- 세션: **Upstash Redis** / 영속 데이터: **D1** / 정적 프론트: **Pages**
