# Leaf — 배포 가이드 (vibequant.cc/Leaf)

> 현재 상태: **MVP 배포 + 보안 강화(로드맵 1단계) 완료** — https://vibequant.cc/Leaf/
> (기존 vibequant-web Pages 사이트는 무영향. `/Leaf*` 경로만 Worker가 처리)

## 구성

```
vibequant.cc/Leaf* → Worker "leaf" (무료 티어)
├─ GET  /Leaf/                       → 뷰어 (ASSETS: public/index.html)
├─ GET  /Leaf/audit                  → 유출 정보 추출 페이지
├─ GET  /Leaf/api/viewer-identity    → 세션·IP·email (시각/비가시 WM용, 쿠키 발급)
├─ GET  /Leaf/api/albums/:id/meta    → 페이지 수 + 서명 URL (세션 필수)
├─ GET  /Leaf/api/albums/:id/pages/:n?exp=&sig= → 워터마크 이미지 (세션+서명+레이트리밋)
├─ POST /Leaf/api/capture-alert      → 캡처 징후 D1 기록 (서버 신뢰소스, detail allowlist)
└─ GET  /Leaf/api/capture-log        → 로그 조회 (Bearer 토큰 필수)
```

유출 이미지 LSB 추출·시각 WM 판독: [`04-유출검증-가이드.md`](./04-유출검증-가이드.md) · 라이브: `/Leaf/audit`

| 리소스 | 이름 | 용도 |
|---|---|---|
| Worker | `leaf` | 라우트 `vibequant.cc/Leaf*` |
| R2 | `leaf-images` | `images/{albumId}/{pageNo}.jpg` (업로드 시 워터마크 사전 합성) |
| D1 | `leaf-db` | `capture_alerts`, `rate_limits` 테이블 |

## 보안 동작 (로드맵 1단계, 2026-08-02 배포)

- **세션 필수화**: `leaf_sid` 쿠키 없는 meta·이미지 요청은 403
- **서명 URL**: meta 응답의 `pages[].url`에 `?exp=&sig=` 포함 (HMAC-SHA256, 세션 바인딩, TTL 120초)
- **레이트리밋** (D1 `rate_limits`, 분당): 이미지 15/세션, 60/IP, 알림 5/세션, meta 10/세션
- **`capture-log` 인증**: `Authorization: Bearer <LEAF_ADMIN_TOKEN>`
- **`capture-alert` 신뢰소스**: 클라이언트 sid/email 무시, 쿠키·CF-IP·allowlist 사용

## secrets (커밋 금지 — Cloudflare secret + 로컬 `.dev.vars`)

```bash
# 1회 설정 (worker 디렉토리에서, 값은 stdin으로 전달)
cat secret-value.txt | npx wrangler secret put LEAF_SIG_SECRET
cat token-value.txt  | npx wrangler secret put LEAF_ADMIN_TOKEN

# 관리자 로그 조회
curl -H "Authorization: Bearer <LEAF_ADMIN_TOKEN>" "https://vibequant.cc/Leaf/api/capture-log"
```

로컬 개발은 `worker/.dev.vars`에 동일 키 입력 (gitignore 대상).

## 새 화보집 이미지 올리기

```bash
# 1) 원본 이미지 폴더 준비 (jpg/png/webp, 페이지 순서대로 파일명 정렬)
# 2) 리사이즈(≤1600px) + 워터마크 합성 + R2 업로드
cd Leaf_OpenEBook/scripts
node prepare-and-upload.js --album 1 --source ./photobook --watermark "Leaf | (원하는 문구)"
```

업로드만 하면 페이지 수는 **R2에서 자동 집계**되므로 Worker 재배포가 필요 없습니다.

## 참고 (의도한 설계 제약)

- **워터마크는 업로드 시 사전 합성** — Workers 무료 티어 CPU 10ms 제한 때문에
  요청 시점 sharp 합성은 불가능 (검증: `docs/02-이미지보호-기술검증.md` §4.5)
- **로그인·결제 게이트는 미도입** — 서명 URL로 "열람 세션"은 통제하나 계정 단위 권한은
  기능명세 P3~P6에서 `pageHandler`에 추가
- **캡처 알림은 "징후 추정"** — 오탐 가능. 로그 축적용 (기능명세 §8)
- **wrangler R2 명령은 `--remote` 필수** — wrangler 4.x는 R2 명령이 기본 로컬 모드

## 로컬 개발

```bash
cd Leaf_OpenEBook/worker
npx wrangler dev --remote   # 실바인딩(R2/D1/secrets) 로컬 검증: http://localhost:8787/Leaf/
npx wrangler d1 migrations apply leaf-db --remote
```
