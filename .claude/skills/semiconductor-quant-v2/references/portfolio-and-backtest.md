## 프롬프트 C — 크라우딩 조정 모멘텀 롱/숏

### 후보 선정
- 롱: composite 상위 1/3 중 `crowd_z < +2.5` (국면별 임계값은 프롬프트 E가 덮어씀)
- 숏: (a) mom_12_1 하위 1/3 **이고** revision < 0, 또는 (b) DIVERGENCE_HIGH **이고** revision < −0.5σ.
  **3M 약세만으로는 숏하지 않는다** (단기 조정 후 반등 위험).
- 숏 금지: days-to-cover > 5, 차입비용 결측/연 5% 초과, 한국 종목은 공매도 가능 여부·차입 가능 수량이 <DATA>에 없으면 후보 제외.
- ⚠ 검증 발견: 유니버스 15종목에서 "상위 1/3"=5종목 < "롱 6~8종목" 규칙 → 종목 수 규칙을 우선하고 data_gaps로 보고. 롱/숏 후보가 겹치면(예: MRVL) 숏에서 제외.

### crowd_z (구성 요소 z 평균, 데이터 지연 함께 기록)
공매도 잔고/유동주식(FINRA, 월 2회) · days-to-cover · 옵션 IV 1년 백분위 · 25Δ 풋−콜 스큐 ·
모멘텀·반도체 ETF(MTUM·SMH·SOXX) 보유 비중 변화 · 13F 헤지펀드 수 변화(분기+45일 지연, **단독 사용 금지, 가중치 ≤ 20%**)

### 사이징
| 항목 | 값 |
|---|---|
| 종목 수 | 롱 6~8, 숏 4~6 |
| 그로스 | 롱 ≤ 120%, 숏 ≤ 70% |
| 종목 상한 | 롱 ≤ 20%, 숏 ≤ 12% (스퀴즈 대비 숏이 더 빡빡) |
| 기본 비중 | ∝ 1/σ60 (60일 실현변동성 역수), 목표 변동성 연 15% |
| crowd_z 조정 | +1.5~+2.0 → ×0.75, +2.0 이상 → ×0.5, 국면별 제외 임계값 이상 → 롱 후보 제외 |
| 서브섹터 | 순노출 \|net\| ≤ 25% (dual_exposure 반영) |

### 리스크 트리거 (단계적 — 전량 청산 아님)
- 자체 모멘텀 L/S 팩터 수익률: 5일 −5% → 그로스 −20%, 10일 −10% → 그로스 −40%
- 종목 변동성 비율 r = σ20/σ90 > 1.5 → 해당 종목 비중 × (1/r)
- 단일 종목 손절: 진입 후 −2.5 × σ20 × √5
- 재진입: 팩터 5일 수익률 > 0 이고 유니버스 중앙값 r < 1.2 가 3거래일 연속 → 줄인 그로스의 50%씩 복원

## 프롬프트 D — 멀티팩터 + 타이밍 + 테일 헤지 + 백테스트

### 팩터 (월말 리밸런싱, 서브섹터 중립 z)
momentum(mom_12_1) · value(B의 서브섹터별 정의) · quality(FCF/총자산 + 5년 EPS 변동성 역수) ·
low_vol(σ60 역수) · size(log 시가총액 — **노출 통제용, 목표 노출 0, 수익 팩터 아님**)

### 기본 가중치
momentum 40 / value 20 / quality 20 / low_vol 20

### 팩터 타이밍 (히스테리시스 포함)
- 자체 모멘텀 L/S 팩터의 12M 롤링 샤프 ≤ 0 이 2개월 연속 → momentum 20, low_vol 40
- 롤링 샤프 > 0.3 이 2개월 연속 → 기본 가중치 복귀
- overlap = Jaccard(mom_12_1 상위 1/3, mom_3m 상위 1/3) < (5년 평균 − 1σ) → momentum 가중치 × 0.5 (전면 제거 금지)

### 테일 헤지
- SMH/SOXX 3개월 풋 스프레드(현물 −10% 매수 / −20% 매도), 월별 롤
- 연간 프리미엄 ≤ NAV 1.5%, 드로다운 −10% 도달 시 명목 ×2 (단 예산 상한 내)

### 백테스트 사양
- 데이터 2020-01~(12M 워밍업), 평가 2021-01~AS_OF
- 워크포워드: 파라미터는 2021~2024에서만 결정, 2025-01~AS_OF는 아웃오브샘플
- 2026-07 모멘텀 붕괴 구간은 "스트레스 테스트"로 별도 보고, 튜닝에 사용 금지
- 결측: 상장 전 N/A, 상장폐지·분할 이력 반영(생존편향 방지)
- 비용: 미국 수수료 3bp + 슬리피지 5bp, 한국 매도 거래세 별도, 숏 차입비용 일할, 옵션 매수·매도 스프레드 절반
- 보고: CAGR, 연 변동성, 샤프, MDD, 칼마, 월 회전율, 헤지 효율 = (스트레스 구간 손실 감소분)/(연 헤지 비용)
