# Project OpenRDHx

**상태**: 공개 설계 v1.2 · 2026-11-22
**성격**: 연구·사업 기획 문서. 용량 숫자는 칼로리미터 실측 전의 설계 목표다. 견적, 인증, 투자 권유가 아니다.
**공개**: 문서·도면은 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), 하드웨어 설계는 [CERN-OHL-W 2.0](https://cern-ohl.web.cern.ch/) 이중 라이선스다. 공개 범위는 **인터페이스**이고, 코일 회로·팬 선정점·제어 상수·펌웨어는 비공개다. 경계는 [`00_오픈아키텍처`](00_오픈아키텍처/오픈아키텍처.md) 3절. 실측 전 숫자를 인증 용량으로 옮겨 적지 않는다.
**환율 가정**: 1 USD = 1,450 KRW. 2026-11-22 문서에 고정한 계획 환율

OpenRDHx는 레거시 공랭 IDC와 **채굴장**을 AI 고전력 실로 올리는 **공개 전환 플랫폼**이다. 여기서 고전력은 랙당 40–50kW 공랭 단계다. 100kW를 넘는 칩 직접 냉각은 플랫폼과 본 사업 범위 밖이다.

- 전환 1, **OpenRDHx-A40**. 기존 800mm 42U 랙의 뒷문. 공기 45→27°C, 물 18→26°C, **40kW**, 풍량 7,000 m³/h, 유량 72 L/min. 도어 160mm, 코일 4열, 팬 7대(6운전+1예비).
- 전환 1-b, **OpenRDHx-A40-600**. 폭 600mm. **28kW**, 4,900 m³/h, 50 L/min, 같은 전면 풍속 1.57 m/s. 기존 랙 유지가 전제인 현장이 많아 옵션이 아니라 2순위 정격이다.
- 전환 2, **OpenRDHx-R50**. 랙과 열교환기가 한 몸. 같은 온도점, 풍량 8,400 m³/h, 유량 86 L/min, **48kW는 계획**이다. 칼로리미터 전에 카탈로그 정격이 아니다.

팔리는 정격은 A40 한 점이다. R50은 같은 물과 같은 레지스터를 쓰는 확장 모듈이다.

- 공기 45°C → 27°C, 물 18°C → 26°C, **40kW**
- 그 점에 필요한 풍량 **7,000 m³/h**, 유량 **72 L/min**
- 도어 **800 × 1,950 × 160 mm**, 코일 **4열** (공기 방향 포락 약 86mm)
- 팬 **7대 = 6운전 + 1예비**, 전원 **AC 1+1**
- 중량 건조 **85kg** / 충수 **97kg** (물 12L)
- **랙 적재 설계점 32kW** — 공랭 8U GPU 서버 2대 + ToR·여유. 3대(46.5kW)는 R50 자리다

12°C 물로 40kW를 내고 결로 밸브를 잠그는 조합은 이 기획에서 뺐다. 공급수 18°C는 데이터센터 권장 노점(상한 15°C, 허용 A1 상한 17°C) 위에 있다. 130kW급 콜드플레이트 랙은 대상이 아니다.

## 사업 구조 한 장

도어를 팔아 개발비를 갚는 계획이 아니다. 자체 IDC 를 짓고, 그 현장이 앵커 물량이면서 레퍼런스가 된다.

| 층 | 무엇 | 역할 |
|---|---|---|
| 1. IDC 운영 | 자체 6.5MW 고밀도 상면 임대 + 전력 | 레퍼런스이자 앵커 물량 |
| 2. 하드웨어 | OpenRDHx 도어 외부 판매 | 단독으로는 연 99대가 인건비 분기점 |
| 3. 전환 EPC | 남의 채굴장·레거시 IDC 의 냉각 패키지 수주 | 1·2층이 있어야 수주 자격이 생긴다 |

```
자체 IDC:  1단계 채굴장 1.5MW 전환 (RDHx 34대) + 2단계 신설 5MW (105대) = 139대
회수점:    정가 250대 − 자체 139대 = 외부에 팔아야 하는 111대
전환비 중 도어 비중: 4–6%.  우리가 수주하는 냉각 패키지: 20–32%
```

도어 단가를 30% 깎아도 전환비는 1.5% 내려간다. 도어가 버는 것은 가격이 아니라 **바닥면적(랙당 10 → 32kW)** 과 **수온(18°C 2차 루프의 프리쿨링 시간)** 이다.

## 바로 다음 행동

1. **고밀도 상면료 kW당 월 단가 견적 3건.** 전체 사업의 분기점이다. 5만 원이면 2단계 5MW 가 성립하지 않는다.
3. **견적을 샘플 구매보다 앞에 둔다.** BEEHE·Ablecom 견적 3건과 팬 PQ 곡선 검토. 질문서에 "45/25°C 행이 공기 온도인지"를 넣는다. BEEHE 페이지는 명시하지 않는다.
4. **1단계 채굴장 부지의 단면도와 바닥 적재 하중 실측.** 천장고와 후면 서비스 1.2m 가 부지를 가장 먼저 탈락시킨다.
5. 코일 업체 2곳에 정격점(40kW, 7,000 m³/h, 72 L/min, 45/27°C, 18/26°C)을 보내고, 풍동 없이 금형 선급을 요구하면 탈락시킨다.
6. FTO 변리사 의견서 착수. CPC H05K 7/20, F28D 1/04, F24F 11/, G06F 1/20.
7. 진천·충북 TMY 시간별 건구·습구로 프리쿨링 시간 재계산. PUE 1.30 의 근거다.
