# OpenRDHx-A40 기술명세서

**문서**: 04_기술명세서 · v1.0 · 2026-11-22
**적용**: 42U, 폭 800mm 랙의 액티브 후면 도어. 600mm는 폭 옵션.
**정격의 지위**: 아래 표는 설계 목표다. 형식 시험 성적서가 나오기 전에는 계약 보증 용량이 아니다.

열수지와 밸브 실패 위치의 근거는 [열정산_및_보호로직.md](열정산_및_보호로직.md).

## 1. 모델

| 항목 | OpenRDHx-A40 | OpenRDHx-A40-600 |
|---|---|---|
| 지위 | 1차 제품 | 폭 옵션, 용량은 잠정 |
| 랙 | 42U × 800mm | 42U × 600mm |
| 정격 열량 | 40kW | 28kW 잠정 |
| 외형 (W×H×D) | 800 × 1,950 × 160 mm | 600 × 1,950 × 160 mm |
| 팬 | 200mm EC × 7 (6운전+1예비) | 동일 팬 팩, 풍량 세트 별도 |
| 도어 전력 상한 | 0.9kW | 실측 후 |
| 계획 중량 | 건조 70kg / 충수 85kg | 건조 60kg / 충수 72kg |

중량은 물 10L를 가정한 계획값이다. 프로토타입에서 저울로 바꾼다.

패시브 모델과 60kW·80kW 모델은 이 명세서에 없다.

## 2. 정격점

| 항목 | 값 |
|---|---|
| 입구 공기 / 출구 공기 | 45°C / 27°C |
| 공급수 / 환수 | 18°C / 26°C |
| 필요 풍량 | 7,000 m³/h |
| 필요 유량 | 72 L/min |
| 유체 | 물. PG25는 대조 시험 전 용량 칸 공란 |
| 전면 풍속 (800mm) | 약 1.6 m/s |
| 공기측 압손 목표 | 100Pa 이하. 실측값으로 교체 |
| 수측 압손 목표 | 정격 유량에서 40kPa 이하. 퀵 커플링 포함 |

35°C 공기 입구, 같은 풍량, 출구 25°C 참고 열량은 **22kW** 다. 40kW 칸에 넣지 않는다.

## 3. 코일

| 항목 | 값 |
|---|---|
| 열수 | 4열, 스태거, 대향류 |
| 관 | C1220, Ø9.52 × 0.41t |
| 헤더 | 동관, 브레이징. 호칭은 제작도에서 확정 |
| 핀 | 알루미늄 0.12t, 피치 2.5mm, 친수 코팅 |
| 공기 방향 피치 | 25.4mm |
| 단 피치 | 25.4mm |
| 포락 | 86mm. 코일 베이 100mm |
| 설계 압력 | 10bar |
| 공장 시험 | 15bar, 30분, 전수 |
| 16bar | 옵션. 시험압은 24bar로 따로 둔다. 10bar용 15bar 시험을 재사용하지 않음 |

0.41t 는 0.35t 대비 부식 여유를 둔 계획 두께다. 업체 표준이 0.35t 이면 부식 여유를 계산으로 보여주고 명세를 고친다.

## 4. 팬과 전원

| 항목 | 값 |
|---|---|
| 팬 | EC 200mm, 축류, PWM, 타코, 핫스왑 |
| 대수 | 설치 7 = 운전 6 + 예비 1 |
| 선정 점 | 운전 6대가 100Pa에서 7,000 m³/h를 최대 속도의 85%로 낼 것 |
| 탈락 조건 | 그 점이 곡선 아래에 있거나, 정격 입력이 0.9kW를 넘김 |
| 대체 구조 | 200mm 축류가 탈락하면 원심 팬으로 바꾸고 도어 두께를 다시 연다. Ablecom CDR42는 원심 4대, 깊이 337mm |
| 전원 | AC 200–240V, 50/60Hz, **인입 2회로(1+1)**. 각 회로가 팬 전부와 제어기를 감당 |
| 24V | SMPS 2대 |
| 대기 | 팬 정지 시 제어기 15W 이하 목표 |

단일 C20 한 개는 기본 사양이 아니다. BEEHE 공개표는 C20 한 칸과 전원 N+1 문장이 같이 있으므로, 샘플 실사 때 전원 경로를 확인한다.

## 5. 배관과 밸브

기본으로 딸려 나오는 것:

- PICV 1개. 0–10V. 실패 위치는 현상 유지.
- 격리 밸브 1개. 스프링 닫힘. 누수 또는 밸브 전원 상실 때 닫힘.
- 퀵 커플링 1쌍. 무누수 분리. 호칭 1인치 계획.
- 접속 위치는 상부 **또는** 하부. 주문서에서 하나. 반대편은 캡과 플러그.
- 체크 밸브, 에어벤트, 코일 배수, 스트레이너는 도어 납품 범위에 포함한다. 행 헤더와 CDU는 포함하지 않는다.

통신 기본은 Modbus TCP/IP이고, RS-485 RTU도 같은 보드에 둔다. BACnet, SNMP, 7인치 화면은 옵션이다. 국내에 유통되는 USystems CL23 데이터시트가 TCP를 기본 프로토콜로 적는다. RTU만 넣으면 그 현장의 DCIM과 바로 맞지 않는다.

## 6. 센서와 I/O

A40 제어기 한 종이 팬 7대를 본다. 더 많은 팬의 상위 모델은 이 기판으로 겸하지 않는다.

| 구분 | 수량 | 쓰는 곳 |
|---|---|---|
| AI | 6 | 출구 공기, 입구 공기, 급수, 환수, 수측 차압, 공기측 차압 |
| 디지털 온습도 | 1 | 노점. AI 6점에 넣지 않음 |
| DI | 4 | 누수, 도어, 화재, 예비 |
| 타코 / PWM | 7 / 7 | 팬 |
| AO | 1 | PICV |
| DO | 3 | 격리 밸브, 경보 릴레이 2 |

로컬 표시는 LED 3색이 기본이다.

| EMC | EN 61000-6-2 / 6-4 목표 |

| 형식 시험 | 열량, 압손, 소음, 팬 1대 정지, 팬 전원 차단, 문 개방 |

소음은 무향실 조건이 정해지기 전에 dBA 숫자를 적지 않는다.

## 8. 설치

- 후면 작업 공간 1.2m.
- 랙이 충수 85kg 도어와 90° 개방 모멘트를 받는지 랙 제작사 확인. 3점 힌지 5만 회는 목표 시험이지 완료된 시험이 아니다.
- 2차 루프. 1차측 7°C 냉수를 도어에 직접 넣지 않는다.
- 수질은 입고 전 시험. pH 7.5–9.0, 전도도 500 µS/cm 이하를 초안으로 두고 코일 업체 한도와 맞춘다.
- 통신은 이더넷(Modbus TCP)이 기본이다. RS-485는 차폐 2심, 세그먼트 32노드 이내로 같이 연다.
- 바닥·측면 밀폐는 우회 풍량을 줄이는 현장 공사다. 도어 개스킷만으로 우회가 0이 되지 않는다.

## 11. 확장 — 랙 일체형 OpenRDHx-R50

R50은 정격 제품이 아니다. A40이 게이트 B를 통과한 뒤에, 같은 온도점으로 칼로리미터에 올리는 계획이다. 50kW를 카탈로그에 미리 적지 않는다.

기존 랙의 힌지가 충수 도어를 받지 못하거나, 열 단계가 40kW를 넘을 때 랙을 교체한다. 열교환기는 여닫이 문이 아니라 랙 뒷벽이다. 그래서 160mm 도어에 원심 팬을 구겨 넣지 않고, 후면 베이를 280mm로 연다.

온도점은 A40과 같다. 열량은 풍량 비로만 올린다.

| 항목 | A40 정격 목표 | R50 계획 |
|---|---|---|
| 공기 | 45°C → 27°C | 같음 |
| 물 | 18°C → 26°C | 같음 |
| 열량 | 40kW | 50kW |
| 필요 풍량 | 7,000 m³/h | 8,750 m³/h (40kW 대비 50/40) |
| 필요 유량 | 72 L/min | 90 L/min (1.5 kg/s × 4.18 × 8K = 50.2kW) |
| 코일 | 4열, 면 약 720 × 1,650mm | 4열 유지. 면 약 720 × 1,880mm |
| 전면 풍속 | 약 1.63 m/s | 약 1.80 m/s. 압손은 다시 잰다. 100Pa 목표를 그대로 약속하지 않음 |
| 팬 | 축류 7대 = 6+1 | 원심. 대수는 PQ 곡선 전이라 비워 둠 |
| 전기 상한 | 0.9kW 목표 | 1.4kW 계획. 8,750 m³/h × 120Pa의 공기 동력은 약 290W |
| 외형 | 도어 800 × 1,950 × 160mm | 48U × 폭 800mm, 후면 베이 280mm |
| 밸브·통신·DRY | 기본과 같음 | 같음. 레지스터 초안도 같음 |

6열로 늘려 50kW를 만들지 않는다. 공기 온도차 18K에서 열량의 한도는 풍량이다. 280mm는 열 수를 늘리는 자리가 아니라 원심 팬과 트레이의 자리다.

중량은 랙 OEM 견적 전에 숫자로 고정하지 않는다. A40의 충수 85kg을 힌지에 매달지 않는다는 점만 고정한다.
