# 자체 5MW IDC — RDHx 앵커 물량과 전환 단가

**문서**: 11_자체IDC_5MW · v1.0 · 2026-11-22
**성격**: 설계 기준과 물량 산출. 견적이 아니고, 승인된 예산이 아니다. 아래 kW·대수·금액은 전부 **계획값**이고, 1차측 설계와 3사 견적으로 교체한다.
**환율**: 1 USD = 1,450 KRW (문서 고정값)
**왜 이 문서가 있는가**: `08_예산` 의 회수 250대 문제는 시장에서 풀리지 않는다. 2027–2029 외부 판매 시나리오는 130대다. 자체 IDC 가 139대를 쓰면 외부에 팔아야 하는 대수가 111대로 내려간다. 이 문서는 그 139대가 어디서 나오는지 센 것이다.

## 1. 2단계 구성

사용자 결정: **기존 채굴장 전환 + 신설 하이브리드**.

| 단계 | 부지 | 수전 | 가동 목표 | 성격 |
|---|---|---:|---|---|
| 1단계 | 기존 채굴장 전환 | 1.5MW | 2027 하반기 | 레퍼런스. 수전·건물·변전 재활용 |
| 2단계 | 신설 전용동 | 5.0MW | 2029 하반기 | 본체. 토지·수전 신규 |

1단계를 먼저 하는 이유는 비용이 아니라 **레퍼런스**다. RDHx 는 칼로리미터 성적서만으로 팔리지 않는다. 4주 이상 운전 기록이 있는 현장이 있어야 2단계와 외부 수주의 제안서가 성립한다. 1단계는 그 기록을 우리가 직접 만드는 공사다.

## 2. 랙 적재 설계점 — 왜 40kW 가 아니라 32kW 인가

A40 의 **정격**은 40kW 다. 그러나 IDC 의 **랙 적재 설계점은 32kW** 로 둔다.

| 구성 | 전력 | 비고 |
|---|---:|---|
| 공랭 8U GPU 서버 (B300급 14.5kW) × 2대 | 29.0kW | NVIDIA 문서상 DGX B300 14.5kW |
| ToR 스위치, 광 모듈, 여유 | 3.0kW | |
| **랙 설계 부하** | **32.0kW** | A40 정격 40kW 대비 여유 20% |

같은 서버 **3대**를 한 랙에 넣으면 43.5 + 3 = 46.5kW 다. A40 의 40kW 를 넘는다. 그 적재는 R50(계획 48kW) 의 자리이고, A40 으로 받겠다고 적지 않는다. 기가바이트 공랭 B300 포드가 랙당 최대 70kW 를 적고 슈퍼마이크로가 52U 랙에 8U 시스템 4대를 싣는 것은 사실이지만, **그 적재는 이 플랫폼의 정격 밖**이다. 2대/32kW 가 A40 이 실제로 받는 구성이다.

이것이 앞선 검토에서 지적된 "40kW 가 서버 대수와 안 맞는다"에 대한 답이다. 정격을 45kW 로 올리지 않고, **적재를 2대로 정의**해서 닫는다. 3대 적재 수요는 R50 48kW 로 보내고, R50 의 칼로리미터를 2단계 일정 안에 넣는다.

## 3. 물량 — RDHx 139대

PUE 1.30 을 설계 목표로 둔다. 근거는 4절.

### 1단계 (채굴장 1.5MW)

```
수전 1,500 kW ÷ PUE 1.30 = IT 1,154 kW
GPU 존   32랙 × 32kW = 1,024 kW   → A40 32대
저밀도 존 6랙 × 20kW =   120 kW   → 룸 공조, 도어 없음
IT 합계              = 1,144 kW   → 수전 1,487 kW  (목표 1,500 kW)
```

RDHx **32대 + 현장 예비 2대 = 34대**

### 2단계 (신설 5MW)

```
수전 5,000 kW ÷ PUE 1.30 = IT 3,846 kW
GPU 존   100랙 × 32kW = 3,200 kW  → A40 100대
저밀도 존 32랙 × 20kW =   640 kW  → 룸 공조
IT 합계               = 3,840 kW  → 수전 4,992 kW  (목표 5,000 kW)
```

RDHx **100대 + 현장 예비 5대 = 105대**

### 합계와 연도 배분

| 연도 | 대수 | 어디에 |
|---|---:|---|
| 2027 | 34 | 1단계 전량 |
| 2028 | 40 | 2단계 1차 (GPU 존 1·2열) |
| 2029 | 65 | 2단계 2차 (잔여 + 예비) |
| **합계** | **139** | |

저밀도 존(네트워크·스토리지·관리) 38랙은 랙당 20kW 라 룸 공조로 받는다. 도어를 달면 대수는 177대가 되지만, 20kW 를 40kW 도어로 받는 것은 과투자다. 그 존에는 달지 않는다.

## 4. 2차 루프와 프리쿨링 — 18°C 가 버는 것

RDHx 의 값은 밀도만이 아니다. **공급수 18°C** 라는 점이 열거부 쪽에서 돈을 번다.

```
2차 공급 18°C
→ 판형 열교환기 접근 2K  → 1차 공급 16°C 필요
→ 건식 프리쿨러 접근 5K → 외기 건구 11°C 이하면 냉동기 정지
```

레거시 룸 공조는 1차 냉수 7°C 를 쓴다. 7°C 를 외기로 만들려면 건구 2°C 이하여야 해서 프리쿨링이 사실상 없다. 18°C 2차 루프는 **연중 상당 시간 냉동기를 끈다**. 충북 내륙의 연평균 건구는 11–12°C 대이고, 11°C 이하 시간은 연간 **약 45–50%** 로 어림된다.

| 운전 | PUE 계획 | 연간 비중 |
|---|---:|---:|
| 프리쿨링 (냉동기 정지) | 1.22 | 48% |
| 냉동기 운전 | 1.38 | 52% |
| **연간 가중** | **1.30** | |

5MW 기준으로 레거시 공랭 PUE 1.60 과 비교하면:

```
절감 전력 = 3,840 kW × (1.60 − 1.30) = 1,152 kW
연 에너지  = 1,152 × 8,760h × 부하율 0.85 = 8,578 MWh
연 절감액  = 8,578 MWh × 150원/kWh ≈ 12.9억 원
```

**이 숫자는 전부 계획값이다.** 세 가지가 확정되기 전에는 제안서 본문에 쓰지 않는다.

1. 진천·충북 TMY 시간별 건구·습구 데이터로 11°C 이하 시간 재계산. 위 48% 는 연평균에서 어림한 값이다.
2. 1차측 구성 확정. 증발 보조(adiabatic) 를 쓰면 습구 기준이 되어 비중이 60%대로 올라가지만 수소비와 수처리가 붙는다.
3. 전력 단가 150원/kWh 확정. 2026년 산업용 평균 단가는 180–185원/kWh 대로 보도되고, 고압A 선택Ⅱ 기본요금 8,320원/kW 와 경부하 비중을 반영한 24시간 평탄 부하의 혼합 단가를 한전 요금표로 다시 계산해야 한다. **130–180원/kWh 밴드**로 민감도를 본다.

PUE 1.60 이라는 비교 기준도 조건이 있다. 랙당 32kW 를 룸 공조로 받는 것은 애초에 불가능하므로, 1.60 은 "같은 전력을 레거시 공랭 밀도(랙당 10kW 대)로 수용했을 때" 다. 바닥면적은 3배가 된다. 전환 판단에서는 맞는 비교지만, "도어를 달면 PUE 가 1.6 에서 1.3 으로 내려간다"는 문장으로 줄이지 않는다.

### 5-3. 도어는 전환비의 4–6% 다

| | 도어 | 냉각 패키지 전체 | 전환비 전체 |
|---|---:|---:|---:|
| 1단계 | $165,000 (5.6%) | $945,000 (32.4%) | $2,920,500 |
| 2단계 | $510,000 (4.0%) | $2,610,000 (20.4%) | $12,799,500 |

냉각 패키지 = 도어 + CDU + 2차 배관 + 열거부 + 제습.

이 표가 이 문서에서 가장 중요하다. **도어 단가를 30% 깎아도 전환비는 1.5% 내려간다.** 그러므로 "중국산보다 싸다"는 포지션은 사업의 중심이 될 수 없다. 도어가 버는 것은 두 가지다.

1. **바닥면적.** 랙당 10kW 를 32kW 로 올리면 같은 전력에 바닥이 1/3 이다. 1단계 채굴장에서 이것은 건물을 더 짓지 않는다는 뜻이다.
2. **수온.** 18°C 2차 루프가 프리쿨링 시간을 만든다. 4절의 연 12.9억 원 계획 절감이 거기서 나온다.

우리가 수주하는 범위는 도어가 아니라 **냉각 패키지 20–32%** 다. 외부 전환 사업의 단가는 이 줄로 제안한다.

## 6. 139대가 프로그램 현금에 하는 일

| | 금액 |
|---|---:|
| 외부 조달 대비 대당 절감 (보수: 우리 정가 $7,400 − 변동비 $4,850) | $2,550 |
| 139대 | **$354,450** (약 5.1억 원) |
| 프로그램 현금 (`08_예산` 4절) | $638,000 |
| 회수 비율 | **56%** |

2차 자료의 액티브 도어 밴드 하단 $8,000 을 기준으로 보면 대당 $3,150, 139대에 $437,850 으로 **69%** 다. 제안서 본문에는 보수 기준 **56%** 를 쓴다.

이 56% 는 **외부에 한 대도 팔지 않았을 때**의 숫자다. 외부 판매는 그 위에 쌓인다.

| | 대수 |
|---|---:|
| 프로그램 현금 회수점 (정가) | 250 |
| 자체 IDC 흡수 | 139 |
| **외부에 팔아야 하는 대수** | **111** |

111대는 2029년 시나리오(2028년 40대 + 2029년 80대 = 120대) 안에 들어간다. 232대·250대가 비현실적으로 보였던 이유는 자체 수요를 세지 않았기 때문이다.

조건이 있다. **IDC 투자가 멈추면 다시 250대다.** 두 사업은 하나의 현금흐름이고, 따로 성립하지 않는다.

## 7. 채굴장 전환의 갭 — RDHx 로 메워지지 않는 것

1단계 부지가 채굴장이라서 싸다. 그러나 채굴장과 AI IDC 의 차이는 냉각만이 아니다. 아래는 **도어로 해결되지 않는** 항목이고, 전부 5절 예산에 줄이 있다.

| 갭 | 채굴장 현황 | AI IDC 요구 | 예산 줄 |
|---|---|---|---|
| 무정전 | UPS 없음. 정전 시 그냥 멈춤 | 학습은 체크포인트로 버팀. 상면 임대·추론은 불가 | UPS 46만 + 발전기 45만 USD |
| 네트워크 | 상향 수 Gbps, 단일 경로 | 랙당 400G × 2, 외부 이중화 | 35만 USD |
| 바닥 하중 | 경량 채굴 랙 | GPU 랙 충수 1,200–1,500 kg/랙 + 도어 97kg | 랙·바닥 보강 15만 USD |
| 천장고·통로 | 컨테이너형은 천장 2.4m, 밀집 배치 | 도어 1,950mm + 상부 배관, 후면 서비스 1.2m | 설계 단계에서 확인. **배치가 안 되면 그 부지는 탈락** |
| 습도 | 외기 직도입. 노점 20°C 초과 상시 | DRY 모드는 `max(18°C, 노점+2K)`. 노점 20°C 면 열량 28kW | 룸 제습 7만 USD. 표는 `00_오픈아키텍처` 5-1절 |
| 전원 품질 | 역률·고조波 관리 느슨 | GPU 서버 PSU 는 THD 민감 | 변전 점검·필터는 설계에서 확인 |
| 인증·보안 | 없음 | 금융·공공 고객은 ISMS-P, 물리보안 | 12만 USD 일부 + 별도 인증비 |

**천장고와 후면 서비스 공간이 가장 먼저 부지를 탈락시킨다.** 도어는 랙 뒤로 1,950mm 높이에 160mm 를 더하고, 유지보수에 1.2m 를 요구한다. 컨테이너형 채굴장은 그 공간이 없다. 1단계 부지 선정의 1번 항목은 전력이 아니라 **단면도**다.

도어의 충수 중량이 v1.1 의 85kg 에서 **97kg** 으로 올라간 것도 여기에 걸린다 (`04_기술명세서` 1절). 기존 랙 힌지가 97kg 과 90° 개방 모멘트를 받지 못하면 랙 교체가 필요하고, 그러면 A40 이 아니라 R50 이 맞는 선택이다. 1단계 현장 실측에서 이것을 먼저 본다.
