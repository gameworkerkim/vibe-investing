# 무료 웹호스팅 가이드 (2026년 7월 갱신판)

> 최종 갱신: 2026-07-19 | 주요 변경: 000webhost·네이버 모두(modoo!)·Glitch 서비스 종료 반영, 닷홈 2026년 정책 변경(무료 SSL 신규 신청 종료, SSH 제거) 반영, Netlify/Vercel/Cloudflare 무료 플랜 최신 한도 갱신

---

## 무료 웹호스팅이란?

무료 웹호스팅은 비용 부담 없이 웹사이트를 운영할 수 있도록 해주는 서비스입니다. 개인 블로그, 포트폴리오, 학습용 프로젝트, 소규모 웹사이트를 시작하기에 좋은 진입점이 됩니다. 다만 "공짜"인 만큼 저장공간, 트래픽, 기능에서 제약이 따르며, 2024~2025년 사이 000webhost, 네이버 모두(modoo!), Glitch 등 유명 무료 서비스가 잇달아 종료되면서 **서비스 지속성 리스크**가 무료 호스팅 선택의 핵심 변수로 부상했습니다.

시장 흐름도 바뀌었습니다. 전통적인 PHP+MySQL형 무료 호스팅은 축소되는 반면, 정적 사이트·서버리스 기반의 개발자 플랫폼(GitHub Pages, Cloudflare, Vercel, Netlify)이 무료 티어의 사실상 표준이 되었습니다.

---

## 무료 웹호스팅의 장점

| 장점 | 설명 |
|------|------|
| **초기 비용 제로** | 홈페이지, 포트폴리오, 블로그를 바로 개설할 수 있습니다 |
| **설치와 설정이 간편** | 드래그 앤 드롭 빌더나 Git 연동 자동 배포로 코딩 부담 없이 사이트 운영이 가능합니다 |
| **학습 및 테스트에 최적** | 웹 개발 연습, CMS 체험, 프로젝트 시험용으로 부담 없이 사용할 수 있습니다 |
| **추후 유료 전환 가능** | 사이트가 성장하면 동일 플랫폼의 유료 플랜으로 업그레이드할 수 있습니다 |

---

## 무료 웹호스팅의 단점

| 단점 | 설명 |
|------|------|
| **저장공간 및 트래픽 제한** | 저장공간 수백 MB~수 GB, 트래픽 월 수 GB~100GB 수준의 제한이 일반적입니다. 일부는 일일 요청 수 제한(예: InfinityFree 일 30,000 히트)을 둡니다 |
| **자체 도메인 제한** | 서브도메인(예: `사용자.github.io`, `사이트명.pages.dev`)이 기본이며, 자체 도메인 연결이 유료 옵션인 경우가 있습니다 |
| **강제 광고** | 일부 서비스(Wix 무료 플랜 등)는 사이트에 광고나 업체 로고를 표시합니다 |
| **성능 및 안정성 저하** | 트래픽 급증 시 속도 저하 또는 계정 일시정지가 발생할 수 있습니다 |
| **상업적 이용 제한** | Vercel Hobby 등 일부 무료 플랜은 약관상 상업적 이용을 금지합니다 |
| **서비스 종료 리스크** | 000webhost(2024), 네이버 모두(2025), Glitch(2025) 사례처럼 무료 서비스는 언제든 종료될 수 있습니다 |
| **보안·지원 취약** | 전문적 보안 조치와 고객 지원이 유료 대비 제한적입니다 |

## 최근 종료된 주요 무료 서비스 (이전 문서 대비 변경사항)

| 서비스 | 종료 시점 | 비고 |
|--------|-----------|------|

| **네이버 모두(modoo!)** | 2025년 6월 | 국내 무료 홈페이지 빌더 대표 서비스 종료. 닷홈빌더 등이 대체재로 부상 |

이전 버전 문서에 포함되어 있던 **000webhost는 더 이상 존재하지 않으므로** 비교 대상에서 제외했습니다.

## 주요 무료 웹호스팅 서비스 비교 (2026년 기준)

### 전통형(PHP + MySQL) 무료 호스팅

| 서비스명 | 저장공간 | 트래픽/요청 제한 | 광고 | 도메인 | 적합한 용도 |
|----------|---------|------------------|------|--------|-------------|
| **InfinityFree** | 약 5GB (파일 수 30,000개 제한) | 대역폭 무제한, 단 일 30,000 히트 제한 | 없음 | 서브도메인/자체 도메인 | 소규모 PHP 사이트, WordPress 테스트 |
| **AwardSpace** | 1GB | 월 5GB 수준 | 없음 | 서브도메인/자체 도메인 | 개인 웹사이트 (무료 플랜은 SSL 미제공 유의) |
| **닷홈** | 기본사양 수백 MB 수준 | 일/월 트래픽 제한 (초과 시 차단) | 없음 | 기본 서브도메인, 자체 도메인은 도메인플러스(월 500원) 필요 | 국내 사용자, 그누보드/간단한 PHP 홈페이지 |
| **Wix (무료 플랜)** | 500MB | 500MB | Wix 광고 표시 | 서브도메인만 | 코딩 없는 드래그 앤 드롭 사이트 |

**닷홈 2026년 변경사항 주의:**
- 2026년 6~7월 공지 기준, 무료호스팅의 **SSH 접속 기능이 제거**되고 일부 PHP 함수가 제한되었습니다.
- **무료 SSL 신규 신청이 종료**되고 구독형 SSL 자동화 서비스로 전환되었습니다.
- 무료호스팅은 계정당 2개, 6개월 단위 연장 방식이 유지됩니다.

### 개발자/정적 사이트 특화 (현재 무료 호스팅의 주류)

| 서비스명 | 특징 | 저장공간 | 트래픽 | 적합한 용도 |
|----------|------|---------|--------|-------------|
| **GitHub Pages** | Git 푸시로 자동 배포, Jekyll 지원 | 저장소 1GB | 월 100GB (소프트 리밋) | 프론트엔드 포트폴리오, 정적 사이트, 프로젝트 문서 |
| **Cloudflare Pages** | 글로벌 CDN(300+ 도시), **무료 대역폭 무제한**, Workers·D1·R2·KV 통합 | - | 무제한 (정적 요청) | 트래픽 변동이 큰 사이트, 엣지 컴퓨팅, 비용 효율 최우선 |
| **Vercel (Hobby)** | Next.js 최적화, 프리뷰 배포, 2026년 Fluid Compute GA | - | 월 100GB, 함수 호출 100만 회 | Next.js/React 프로젝트. **상업적 이용 금지 약관 주의** |
| **Netlify (Free)** | GitHub 연동, 폼 기능, SSL 제공 | - | 월 100GB, **빌드 300분→100분으로 축소** | JAMstack, 콘텐츠 중심 사이트 |
| **Firebase Hosting (Spark)** | Google 제공, Google 생태계 연동 | 10GB | 일일 전송량 제한 방식 | Firebase 인증/DB 연동 프로젝트 |
| **Render (Free)** | 백엔드 API 무료 티어 제공 | - | 무료 웹서비스는 유휴 시 슬립, 무료 PostgreSQL은 30일 만료 | 풀스택 실습, Node.js/Python 데모 |

2026년 기준 3대 플랫폼의 포지셔닝은 비교적 명확합니다: **Next.js 풀스택은 Vercel, 트래픽이 많은 정적/엣지 워크로드는 Cloudflare, 폼·CMS 연동 중심 JAMstack은 Netlify**로 정리되는 추세입니다. 특히 Vercel 무료 플랜은 월 100GB 초과 시 과금이 시작되므로, 트래픽 예측이 어려운 사이트는 대역폭 무제한인 Cloudflare Pages가 안전한 선택입니다.

## 어떤 서비스를 선택해야 할까?

| 상황 | 추천 서비스 |
|------|-------------|
| **코딩 없이 사이트 만들고 싶다** | Wix(광고 감수), 닷홈빌더 |
| **개발자 포트폴리오/정적 사이트** | GitHub Pages, Cloudflare Pages |
| **Next.js/React 프로젝트** | Vercel(비상업), Cloudflare Pages |
| **트래픽 예측이 어렵거나 급증 가능성** | Cloudflare Pages (대역폭 무제한) |
| **PHP + MySQL이 필요한 사이트** | InfinityFree, AwardSpace, 닷홈 |
| **백엔드 API까지 직접 개발** | Render, Cloudflare Workers, Firebase |
| **한국어 지원과 국내 서버** | 닷홈 |

## 주의사항

1. **상업용/대규모 사이트에는 부적합** — 트래픽 제한과 성능 이슈 외에, Vercel Hobby처럼 약관상 상업적 이용 자체가 금지된 플랜도 있습니다. 비즈니스 사이트는 유료 호스팅을 권장합니다.

2. **서비스 종료 가능성은 이론이 아니라 현실** — 000webhost(2024), 네이버 모두(2025), Glitch(2025)가 실제로 종료되었습니다. 무료 호스팅 이용 시 언제든 이전할 수 있도록 소스와 데이터를 로컬/Git에 보관하세요. Git 기반 배포 플랫폼(GitHub Pages, Cloudflare, Vercel, Netlify)은 저장소 자체가 원본이므로 이 리스크에 구조적으로 강합니다.

3. **SSL 정책 변화 확인** — 정적 배포 플랫폼들은 SSL을 자동 제공하지만, 전통형 무료 호스팅은 정책이 바뀔 수 있습니다. 닷홈은 2026년 7월부로 무료 SSL 신규 신청을 종료했습니다.

4. **숨은 제한 확인** — 저장공간·트래픽 외에 일일 요청 수(히트), 파일 개수(inode), CPU 점유율, 빌드 시간 같은 숨은 제한이 실질적 병목인 경우가 많습니다. Netlify는 무료 빌드 시간을 월 100분으로 축소했습니다.

5. **데이터 백업 필수** — 무료 서비스는 백업 기능이 부족하므로 정기적인 수동 백업이 필요합니다.

---

## 결론

무료 웹호스팅은 **학습, 테스트, 개인 포트폴리오** 용도로는 여전히 훌륭한 선택이며, 특히 정적 사이트라면 2026년 현재의 무료 티어(GitHub Pages, Cloudflare Pages 등)는 사실상 유료급 인프라를 제공합니다. 반면 전통형 PHP 무료 호스팅 시장은 축소·정책 강화 추세이므로, 동적 사이트를 무료로 운영할 계획이라면 서비스 지속성과 제한 정책 변화를 반드시 모니터링해야 합니다. 사이트가 성장하면 유료 호스팅 전환을 조기에 검토하는 것이 안전합니다.
