# quant-market-brief 安装与使用指南

> 一个通过量化视角(因子、波动率、资金流向、市场机制)总结当日
> 股市行情的Claude Skill。
> 相关理念与设计背景请参见[Claude_skill_guide.md](./Claude_skill_guide.md)第5章。

---

## 1. 该技能的功能

只需一句"总结一下今天的市场情况",即可生成**结构化的市场机制简报**,而非简单罗列新闻。

- **触发短语**:"市场行情"、"今天的盘面"、"市场简报"、"盘面总结"、"今天KOSPI/纳斯达克怎么样"等
- **输出结构(固定)**:
  1. 一行市场机制判定 — `市场机制: Risk-On|Risk-Off|Rotation|Chop(置信度: 高|中|低)— 依据`
  2. 数值表格(指数/波动率/利率/汇率/资金流向,标注来源和基准时间)
  3. 因子评分卡(动量、成长/价值、大盘/小盘、质量共4个维度)
  4. "与昨天相比的变化"——只描述变化部分
  5. 反证条件——若判定错误,明天会观察到哪些指标
- **设计原则**:强制网页搜索(不依赖记忆回答)、禁止预测(仅允许条件性场景)、禁止发出买卖指令

由于市场机制判定行始终采用固定格式,`portfolio-daily-review`等其他技能可以解析并复用该结果。

## 2. 安装方法

请从以下三种方式中选择一种。

### 方式A:Claude.ai(网页版/应用)——推荐

1. 将本仓库中的整个技能文件夹压缩为zip,或准备已分发的`.skill`文件。
   ```bash

   zip -r quant-market-brief.skill quant-market-brief/
   ```
2. 在Claude.ai中依次进入**Settings → Capabilities → Skills**上传。(需付费计划)
3. 上传后,在新对话中说出触发短语即可自动激活。

### 方式B:Claude Code

将整个文件夹复制到个人技能目录中:

```bash
cp -r quant-market-brief/ ~/.claude/skills/quant-market-brief/
```

重启Claude Code后,只需用自然语言提及即可使用。

### 方式C:Claude API

参考[Skills API Quickstart](https://docs.claude.com/en/api/skills-guide#creating-a-skill)
上传`.skill`包,即可在API调用中以相同方式运行。

```markdown
# Quant Market Brief

## 目的

解读市场结构(市场机制),而非个别新闻。回答的不是"发生了什么",
而是"从因子、波动率、资金流向的角度看,市场处于哪种机制,与昨天
相比发生了什么变化"。

原则:**观察到的事实 → 因子解读 → 条件性场景。** 绝不进行预测。

## 工作流

### 第1步:数据采集(必须通过网页搜索)

以下内容必须通过网页搜索确认。不得凭训练数据中的记忆回答。
所有数值都必须标注来源和基准时间。

- **主要指数**:KOSPI、KOSDAQ、S&P 500、NASDAQ、费城半导体指数
  (SOX)——收盘价/涨跌幅
- **波动率**:VIX水平及较前一日的变化率、VKOSPI
- **利率/汇率**:美国10年期国债收益率、美元/韩元汇率、美元指数(DXY)
- **资金流向**:KRX外资/机构净买入、主要行业ETF资金流向
- **加密货币(可选)**:BTC价格、"泡菜溢价"——仅作为风险偏好的
  代理指标使用,不直接作为方向性信号

若用户指定特定市场(仅韩国、仅美国),则聚焦该市场,但始终包含
全球风险指标(VIX、利率、美元)。

### 第2步:应用因子视角

阅读`references/factor-checklist.md`,判定以下4个维度:

1. **动量 vs 反转**:近期领涨股是延续上涨还是出现转向?
2. **成长 vs 价值**:利率方向与风格轮动之间的一致性
3. **大盘 vs 小盘**:风险偏好是否已扩散至小盘股?
4. **质量/低波动**:资金是否正流向防御性因子?

每个维度按看涨/中性/看跌进行判定,并附一句话依据。

### 第3步:市场机制判定

明确归类为以下四种之一,并附一句话依据:

- **Risk-On(风险偏好)**:风险资产广泛上涨,波动率下降,小盘股/
  加密货币同步走强
- **Risk-Off(风险规避)**:偏好防御性资产,波动率急升,避险货币走强
- **Rotation(轮动)**:指数持平,但板块/风格之间的资金流动明显
- **Chop(震荡)**:缺乏方向性,交易额低迷,因子信号相互矛盾

将判定的置信度标注为高/中/低。若数据相互矛盾,直接如实标注为
"矛盾",不要强行构造单一叙事。

### 第4步:输出

遵循`references/output-template.md`中的模板。必须包含以下要素:

1. **一行市场机制判定**(置于最上方,包含置信度)
2. **数值表格**(指数/波动率/利率/汇率/资金流向)
3. **因子评分卡**(4个维度,各自附判定结果+一句话依据)
4. **"与昨天相比的变化"**——聚焦变化部分。不重复与昨天相同的内容
5. **反证条件**——若今天的判定错误,明天会观察到什么

## 指导原则

- 不进行预测。只以条件性场景("若X持续,则Y机制延续")进行描述。
- 所有数值都必须标注来源和基准时间。
- 不使用投资招揽性表述("买入/卖出/加仓")。仅提供决策参考材料。
- 新闻标题仅在因子解读所需时才引用。禁止简单罗列标题。
- 若在收盘前请求,须明确说明"为盘中数据,收盘后可能发生变化"。
- 由于其他技能(如portfolio-daily-review)可能复用此简报的市场机制
  判定结果,市场机制判定行必须始终保持相同格式:
  `市场机制: {Risk-On|Risk-Off|Rotation|Chop}(置信度: {高|中|低})— {一句话依据}`
```

### 4.2 references/factor-checklist.md

```markdown
# 因子检查清单

每个因子按**看涨/中性/看跌**进行判定,并留下一句话依据。若信号相互
矛盾,标注为"矛盾",并写明是哪些指标之间存在冲突。

## 1. 动量 vs 反转

- **检查指标**:近1个月表现最佳板块的当日相对收益率、领涨股交易金额
- **动量看涨**:领涨板块相对收益率>大盘 且 交易金额维持或以上
- **动量崩溃信号**:领涨股大幅下跌+成交量激增(分散式卖出模式)
- **反转信号**:近期跌幅过大的股票群体出现广泛反弹+空头仓位减少

## 2. 成长 vs 价值

- **检查指标**:美国10年期国债利率方向、成长股指数(NASDAQ) vs
  价值股相对表现
- **一致性检查**:若出现"利率上升+成长股走强"这类"不一致"组合,
  必须单独标注——这种不一致可能是市场机制转换的早期信号
- **注意**:不要仅凭一天的数据就断定风格轮动。应同时提及3~5个
  交易日的累积方向

## 3. 大盘 vs 小盘

- **检查指标**:KOSPI vs KOSDAQ相对表现、罗素2000指数 vs S&P 500
- **风险偏好扩散**:小盘股指数跑赢大盘股+交易金额增加
- **风险偏好收窄**:大盘股集中度加深(指数上涨集中在少数股票上)
  ——即便是上涨行情,市场宽度恶化也应单独标注为看跌信号

## 4. 质量/低波动(防御性因子)

- **检查指标**:必需消费品/公用事业/医疗保健板块相对表现、股息类
  ETF的资金流入
- **防御性转移信号**:若指数持平至上涨,但防御性板块表现更优,
  应标注可能存在聪明资金提前防御性布局的情况

## 波动率机制(所有因子判定的背景)

| VIX水平 | 机制 | 含义 |
|---|---|---|
| < 15 | 低波动率 | 有利于套利/动量策略,但对急剧反转较为脆弱 |
| 15–25 | 中性 | 按因子信号本身进行解读 |
| > 25 | 高波动率 | 低波动/质量因子占优,应考虑减仓的区间 |

**注意**:VIX的"变化率"比其"绝对水平"更能作为有效的短期信号。
无论绝对水平如何,只要较前一日跳升+20%以上,都应单独标注为警示。

## 资金流向解读原则

- 外资净买入应与美元/韩元的方向结合解读(以区分汇率对冲流动)
- 机构净买入应尽可能区分程序化交易与非程序化交易
- 不要仅凭一天的资金流向就判断趋势,应同时标注5个交易日的累积数据
```

## 5. 使用示例

```
> 今天市场表现如何?

[quant-market-brief激活]
1. 网页搜索:KOSPI/NASDAQ/VIX/10Y/汇率/KRX资金流向
2. 使用factor-checklist.md判定4个维度
3. 市场机制分类+置信度
4. 按output-template.md的格式输出简报
```

若仅想了解特定市场:"只帮我梳理一下美国市场的行情"——全球风险指标(VIX·利率·美元)始终会包含在内。

## 6. 自定义要点

| 项目 | 位置 | 方法 |
|---|---|---|
| 添加/删除追踪指数 | SKILL.md第1步 | 修改指数列表(例如:添加日经指数、恒生指数) |

## 7. 注意事项

- 本技能的输出**是决策参考材料,而非投资建议。**
- 数据以网页搜索时点为准,若在盘中查询,收盘后可能发生变化。
- 该技能仅用于演示/教育目的,实际使用前请在自己的环境中充分测试。
