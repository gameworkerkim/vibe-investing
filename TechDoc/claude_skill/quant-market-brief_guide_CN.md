# quant-market-brief 安装与使用指南

> 一款从量化角度(因子、波动率、资金流、市场状态)总结今日股市行情的Claude Skill
> 关于概念与设计背景,请参见[Claude_skill_guide.md](./Claude_skill_guide.md)第5章

---

## 1. 这个技能能做什么

只需一句"总结今天的市场情况",即可生成一份**结构化的市场状态简报**,而非简单的新闻列表。

- **触发短语**:"市场情况"、"今天的行情"、"市场简报"、"行情总结"、"今天KOSPI/纳斯达克怎么样"等
- **输出结构**(固定):
  1. 一行市场状态判定——`市场状态: Risk-On|Risk-Off|Rotation|Chop (置信度: 高|中|低) — 依据`
  2. 数值表格(指数/波动率/利率/汇率/资金流,注明来源与截止时间)
  3. 因子评分卡(动量、成长/价值、大盘/小盘、质量共4个维度)
  4. "与昨日相比的变化"——只描述变化量
  5. 反证条件——若今日判定有误,明日会观察到哪些指标
- **设计原则**:强制网络搜索(不凭记忆回答)、禁止预测(仅给出条件性情景)、禁止下单指令

市场状态判定行采用固定格式,便于其他技能(如`portfolio-daily-review`)解析并复用。

## 2. 安装方法

从以下三种方式中任选一种。

### 方式A:Claude.ai(网页/App)——推荐

1. 将本仓库的技能文件夹整体打包为zip,或准备已分发的`.skill`文件。
   ```bash
   # 若直接从文件夹创建(zip与.skill格式相同)
   zip -r quant-market-brief.skill quant-market-brief/
   ```
2. 在Claude.ai的**Settings → Capabilities → Skills**中上传。(需付费计划)
3. 上传后,在新对话中说出触发短语即可自动激活。

### 方式B:Claude Code

将整个文件夹复制到个人技能目录:

```bash
cp -r quant-market-brief/ ~/.claude/skills/quant-market-brief/
```

重启Claude Code后,只需用自然语言提及即可使用。

### 方式C:Claude API

参考[Skills API Quickstart](https://docs.claude.com/en/api/skills-guide#creating-a-skill)
上传`.skill`包,即可在API调用中以相同方式工作。

> **验证小技巧**:安装后询问"告诉我现在可用的技能",即可确认是否成功加载。

```markdown
# Quant Market Brief

## 目标

读懂市场结构(状态),而非单条新闻。回答的不是"发生了什么",而是
"从因子·波动率·资金流的角度看,市场处于哪种状态,与昨天相比发生了什么变化"。

原则:**观察到的事实 → 因子解读 → 条件性情景**。不进行预测。

## 工作流

### 第1步:数据收集(必须通过网络搜索)

以下内容必须通过网络搜索确认,不能凭训练数据中的记忆回答。
所有数值都要注明来源与截止时间。

- **主要指数**:KOSPI、KOSDAQ、S&P 500、NASDAQ、费城半导体指数(SOX)
  ——收盘价/涨跌幅
- **波动率**:VIX水平及较前一日的变化率、VKOSPI
- **利率/汇率**:美国10年期国债收益率、韩元/美元汇率、美元指数(DXY)
- **资金流**:KRX外资/机构净买入、主要行业ETF资金流向
- **加密货币(可选)**:比特币价格、泡菜溢价——仅作为风险偏好的代理指标使用,
  不直接用作方向性信号

若用户指定特定市场(仅韩国、仅美国),则聚焦该市场,但始终包含
全球风险指标(VIX、利率、美元)。

### 第2步:应用因子视角

阅读`references/factor-checklist.md`,判定以下4个维度:

1. **动量 vs 反转**:近期领涨股是继续上涨,还是转弱?
2. **成长 vs 价值**:利率方向与风格轮动是否一致?
3. **大盘 vs 小盘**:风险偏好是否已扩散至小盘股?
4. **质量/低波动**:资金是否流向防御性因子?

每个维度判定为强/中性/弱,并附一行依据。

### 第3步:市场状态判定

明确归类为以下四种之一,并附一行依据:

- **Risk-On**:风险资产广泛上涨,波动率下降,小盘股/加密货币同步走强
- **Risk-Off**:偏好防御性资产,波动率急升,避险货币走强
- **Rotation**:指数停滞,但行业/风格之间的资金转移明显
- **Chop**:缺乏方向性,成交额低,因子信号相互矛盾

将判定置信度标注为高/中/低。若数据相互矛盾,直接写"矛盾"。
不要强行构造统一的叙事。

### 第4步:输出

遵循`references/output-template.md`中的模板。必须包含以下要素:

1. **一行市场状态判定**(置于最上方,包含置信度)
2. **数值表格**(指数/波动率/利率/汇率/资金流)
3. **因子评分卡**(4个维度,每个维度给出判定+一行依据)
4. **"与昨日相比的变化"**——聚焦于变化量,不重复与昨天相同的内容
5. **反证条件**——若今日判定有误,明日会观察到什么

## 指导原则

- 不进行预测。只用条件性情景描述("若X持续,则Y状态延续")。
- 所有数值都要注明来源与截止时间。
- 不使用投资建议性措辞("买入/卖出/增加仓位")。只提供决策依据。
- 新闻标题只在因子解读所需时引用,禁止单纯列举标题。
- 若请求发生在收盘前,须说明"这是盘中数据,收盘后可能发生变化"。
- 由于其他技能(如portfolio-daily-review)可能复用本简报的市场状态判定,
  市场状态判定行必须始终保持相同格式:
  `市场状态: {Risk-On|Risk-Off|Rotation|Chop} (置信度: {高|中|低}) — {一行依据}`
```

### 4.2 references/factor-checklist.md

```markdown
# 因子检查清单

每个因子判定为**强/中性/弱**,并留下一行依据。
若信号相互矛盾,标注为"矛盾",并说明哪些指标之间存在冲突。

## 1. 动量 vs 反转

- **检查指标**:近1个月收益率最高行业的当日相对收益率、领涨股成交额
- **动量强**:领涨行业相对收益率>大盘 && 成交额维持或增加
- **动量崩溃信号**:领涨股急跌+成交量骤增(分散抛售模式)
- **反转信号**:近期超卖股票群体出现广泛反弹+空头持仓减少

## 2. 成长 vs 价值

- **检查指标**:美国10年期利率方向、成长股指数(NASDAQ) vs 价值股相对表现
- **一致性检查**:若出现利率上升+成长股走强等"不一致"组合,必须单独标注——
  不一致可能是市场状态转换的早期信号
- **注意**:不要仅凭单日数据断定风格轮动。应同时提及最近3~5个交易日的
  累积方向

## 3. 大盘 vs 小盘

- **检查指标**:KOSPI vs KOSDAQ相对表现、Russell 2000 vs S&P 500
- **风险偏好扩散**:小盘股指数跑赢大盘股+成交额增加
- **风险偏好收窄**:大盘股集中度加剧(指数上涨集中在少数个股)
  ——即便处于上涨行情,broadth(市场宽度)恶化也应单独标注为看跌信号

## 4. 质量/低波动(防御性因子)

- **检查指标**:必需消费品/公用事业/医疗保健的相对表现、股息类ETF资金流入
- **防御性转移信号**:若指数横盘至上涨,但防御性行业跑赢大盘,
  应标注聪明资金可能已提前进行防御性布局

## 波动率状态(所有因子判定的背景)

| VIX水平 | 状态 | 含义 |
|---|---|---|
| < 15 | 低波动 | 有利于套利/动量策略,但容易遭遇急剧反转 |
| 15~25 | 中性 | 按字面意义解读因子信号 |
| > 25 | 高波动 | 低波动/质量因子占优,考虑减仓 |

**注意**:VIX的"变化率"比"绝对水平"更能作为有效的短期信号。
与前一日相比跳升20%以上时,无论绝对水平如何,都应单独标注为警告。

## 资金流解读原则

- 外资净买入应结合韩元/美元方向一并解读(区分是否为汇率对冲流动)
- 机构净买入应尽可能区分程序化与非程序化交易
- 不要仅凭单日资金流判断趋势,应同时标注最近5个交易日的累计数据
```

## 5. 使用示例

```
> 今天市场怎么样?

[quant-market-brief 触发]
1. 网络搜索:KOSPI/NASDAQ/VIX/10年期利率/汇率/KRX资金流
2. 使用factor-checklist.md进行4维度判定
3. 市场状态分类+置信度
4. 按output-template.md格式输出简报
```

只想了解某一市场时:"只帮我整理一下美国市场的行情"——全球风险指标(VIX、利率、美元)始终会包含在内。

## 6. 自定义要点

| 项目 | 位置 | 方法 |
|---|---|---|
| 添加/删除跟踪指数 | SKILL.md 第1步 | 修改指数列表(例如添加日经、恒生指数) |
| VIX状态阈值 | factor-checklist.md | 调整15/25的边界值 |
| 添加因子维度 | factor-checklist.md + SKILL.md 第2步 | 例如添加股息、规模因子 |
| 输出语言/格式 | output-template.md | 直接修改模板 |

## 7. 注意事项

- 本技能的输出是**决策依据,而非投资建议。**
- 数据以网络搜索时点为准,盘中查询时收盘后可能发生变化。
- 本技能用于演示/教育目的,实际使用前请在自己的环境中充分测试。
