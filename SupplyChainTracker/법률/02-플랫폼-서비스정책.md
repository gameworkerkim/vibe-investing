# 플랫폼 서비스 정책

- Version: 1.0
- Date: 2026년 11월 22일
- 대상: SupplyChainTracker 플랫폼 (Korea–US Procurement Sourcing)

---

# 1. 회원 가입 정책

## 1.1 이메일 로그인 + 관리자 승인

- **이메일/비밀번호 기반 로그인만 지원한다.** (소셜 로그인 미지원)
- 회원 가입 신청 후 **관리자가 대시보드에서 검토·승인**해야 로그인이 허용된다.
- 승인 전 계정은 `pending` 상태이며 로그인 시 안내 메시지를 반환한다.
- 거부된 계정은 `rejected` 상태로 전환한다.

## 1.2 초기 관리자 및 비밀번호 강제 변경

- 초기 관리자 계정은 마이그레이션으로 시드한다 (운영 배포 전 교체).
- 시드 계정을 포함한 모든 관리자 계정은 **최초 로그인 직후 비밀번호 강제 변경**한다.
- 강제 변경 완료 전에는 대시보드 내 다른 기능을 사용할 수 없다.

## 1.3 비밀번호 관리

- 비밀번호는 평문 저장 금지. **PBKDF2-SHA256 (반복 100,000회, 랜덤 솔트)** 해시로 저장한다.
- 최소 8자 이상을 요구한다.
- Workers 무료 티어 CPU 시간(요청당 10ms) 제한으로 PBKDF2 연산이 초과할 수 있으므로, 운영 시 Workers 유료 플랜 또는 반복 횟수 조정을 검토한다.
- 세션은 랜덤 토큰 기반 쿠키(HttpOnly, SameSite=Lax)로 관리하고 D1 `sessions` 테이블에 만료 시각을 저장한다.

# 2. 데이터 정책

## 2.1 공개 데이터 원칙

- 초기 버전은 **공개 정보(Public)만 처리**한다. (SAM.gov 공개 API, FPDS 등)
- CUI(통제 비공개 정보) 문서는 업로드 단계에서 차단한다.
- CUI 취급이 필요한 경우 격리 환경과 CMMC 요건을 별도 검토한다. (`법률/01-조달규정-컴플라이언스.md` 참조)

## 2.2 데이터 출처 추적

- 모든 수집 데이터는 출처(Source URL, 수집 시각, API 응답 원문)를 보관한다.
- AI 분석 결과는 원문 근거 문장과 분리하여 저장하고, 원문 인용을 함께 표시한다.

## 2.3 데이터 보관

- 조달 공고 원문과 첨부 문서는 S3 호환 스토리지에 원본 그대로 보관한다.
- 감사 로그(Audit Log)는 삭제하지 않는다.

---

# 3. 개인정보 보호

- 이용자 개인정보(이메일, 이름)는 서비스 운영 목적으로만 사용한다.
- 대한민국 개인정보보호법(PIPA)과 이용자 거주지의 관련 법령을 준수한다.
- 개인정보 처리방침 및 이용약관을 서비스 오픈 전 작성·고지한다.
- 탈퇴 시 계정 데이터는 관련 법령상 보관 의무가 있는 항목을 제외하고 삭제한다.

---

# 4. 접근 통제

| 역할 | 권한 |
|---|---|
| Admin | 전체 설정, 사용자 승인·거부, Audit Log 열람 |
| Member | 공고 분석, 매칭, 견적, 규제 검토 (승인된 사용자) |
| Pending | 로그인 불가 (관리자 승인 대기) |

- 입찰 제출·가격 확정은 Admin 이상의 명시적 승인을 요구한다.
- 모든 주요 업무(분석·매칭·견적·승인)는 Audit Log에 기록한다.

# 5. 향후 검토 항목

- 미국 파트너 계정에 대한 SAM/UEI 등록 상태 연동
- 유료 구독 결제 시 별도 결제 정보 정책
