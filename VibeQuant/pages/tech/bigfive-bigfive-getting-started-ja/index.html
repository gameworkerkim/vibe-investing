Team Big Five Harness — 非開発者のためのスタートガイド

コードを一行も知らなくても真似できるように作られた案内書

コードを一行も知らなくても真似できるように作られた案内書です。 原本: https://github.com/tobyilee/team-bigfive

0. 一文要約

複数のAIが「一つのチーム」のように役割を分けて協業させ、同じAIでもより良い成果物を出す設定の組み合わせです。

平凡な人を複数集めてもチームワークが良ければ結果が良くなる — このチーム科学(Team Science)の発見をAIエージェントにそのまま移したものです。より賢いAIを使うのではなく、AI同士がより良く協力するようにすることが核心です。

1. まず知っておくべき概念3つ

非開発者が最も混乱しやすい部分から取り上げます。

(1) これは「プログラム」ではなく「設定の組み合わせ」です

ダブルクリックすると実行されるアプリではありません。Claude Codeというツールの上に載せて使うルール・役割ファイルの集まりです。例えるなら、料理人(AI)に渡す「レシピ+厨房業務分担表」だと考えれば良いです。

(2) 「Claude Code」がなければ動作しません

Claude CodeはAnthropicが作った、ターミナル(黒いコマンドウィンドウ)でClaudeに作業を指示するツールです。Big Five Harnessはこのclaude Codeの動作方式を「チームモード」に変える追加設定です。

(3) 「ハーネス(Harness)」という言葉の意味

ハーネスは元々「馬にかぶせる馬具(くびき・鞍の組み合わせ)」です。ここではAIが好き勝手に動くのではなく、決められた協業手順に従うように固定する枠組みという意味で使います。

2. なぜ使うのか — 何が良くなるのか

AI一つに大きな作業を一度に指示すると次のような問題が発生します。

  • 前で決めた内容を後で忘れる。
  • お互いに噛み合うべき二つの成果物(例: アプリの画面と裏側)が合わない。
  • 一人で作業するため自分の失敗を自分で気づけない。

Big Five Harnessはこれを人間のチームが働く方式で解決します。

人間のチームでは このハーネスでは
チームリーダーが目標を決め仕事を分ける team-lead(チームリーダーAI)
チームメンバーが各自担当の仕事をする contributor(作業者AI、複数)
一人が同僚たちの作業を相互点検 performance-monitor(検収AI)
ホワイトボードに共同目標を書いておく SMM.md(共有メモファイル)
指示を受けると「OK、〜ということですね?」と確認 メッセージ確認・再述の手順

核心効果: 結果物同士が噛み合う必要がある複雑な作業ほど効果が大きいです。

3. いつ使い、いつ使わないか

最も重要な判断基準です。無条件に使えば良いというものではありません。

使うと良い場合(互いに噛み合う作業)

  • 「このAPIを設計して画面連携まで一度にやって」
  • 「このテーマの複数資料を集めて一つに総合・検証して」
  • 「小説の世界観と筋書きを前後合わないことなく一緒に作って」

使わない方が良い場合(単純または別々に動く作業)

  • 「この単語は英語で何?」のような単純な質問
  • 一度で終わる短い作業
  • 互いに影響のない独立した作業複数(これは単に別々に指示する方が速い)

例え: キンパ一本を巻くのに5人がかかると逆に遅くなります。コース料理のように複数の段階が噛み合う時にチームが光ります。

4. インストール(Getting Started)

非開発者基準で最も詰まりやすい区間なので、一段階ずつ解いて書きます。 順序: ① Claude Codeの準備 → ② ハーネスファイルの受け取り → ③ 自分の作業フォルダに入れる → ④ 実行確認

段階① Claude Codeの準備

Big Five HarnessはClaude Codeの上で動きます。まだなければClaude Codeを先にインストールする必要があります。

  • Claude Codeはターミナルで使うツールであり、Anthropicアカウント(Claude サブスクリプション)が必要です。
  • インストール方法はAnthropic公式ドキュメントに従うのが最も正確です。(「Claude Codeインストール」で検索)
  • インストールが終わると、作業するフォルダでclaudeと入力するとClaude Codeが起動します。

ターミナルが初めてなら: Macは「ターミナル」、Windowsは「PowerShell」または「コマンドプロンプト」がその黒いウィンドウです。

段階② ハーネスファイルの受け取り

GitHubページ(https://github.com/tobyilee/team-bigfive)からファイルを受け取ります。二つの方法のうち楽な方を選んでください。

方法A — ボタンで受け取る(一番簡単、推奨)

  1. 上記GitHubアドレスに入ります。
  2. 緑色のCodeボタンを押します。
  3. Download ZIPを押します。
  4. 受け取った圧縮ファイルを解凍します。

方法B — コマンドで受け取る ターミナルに以下をそのまま貼り付けます。

git clone https://github.com/tobyilee/team-bigfive.git

段階③ 自分の作業フォルダに入れる

これが核心です。ハーネスの脳に該当するフォルダは.claudeとCLAUDE.mdファイルです。

  1. 受け取ったファイルの中で.claudeというフォルダとCLAUDE.mdファイルを探します。
    • (.で始まるフォルダは隠しファイル処理されて見えない場合があります。ファイルエクスプローラーで「隠しファイルを表示」をオンにしてください。)
  2. この二つを、実際に作業するプロジェクトフォルダにそのままコピーして入れます。

コピー後の自分の作業フォルダの様子:

私の-プロジェクト-フォルダ/
├── .claude/          ← ハーネスの役割・手順定義(コピーして入れた)
├── CLAUDE.md         ← ハーネス案内ファイル(コピーして入れた)
└── (自分の作業ファイル…)

段階④ 実行確認

  1. そのフォルダでターミナルを開きclaudeを入力してClaude Codeを起動します。
  2. 以下4章「使用例」のトリガー文を入力してみます。
  3. AIが一人で答えず「チームを構成する/役割を分ける」というふうに動けば正常動作です。

要点だけ再確認: インストール=.claudeフォルダとCLAUDE.mdを自分の作業フォルダに入れることです。それだけです。

5. 使い方 — 「トリガー文」がすべて

インストールが終わったら、複雑なコマンドは必要ありません。 いつものように日本語でお願いしつつ、以下の「魔法の言葉」を一つだけ入れるとチームモードが起動します。

トリガーワード(このうち一つが入れば良い)

  • 「チームで」
  • 「エージェントチーム」
  • 「チームビッグファイブ」
  • 「高性能チーム」
  • 「複数エージェントで」
  • 「協業で処理」

文を作る公式

[やりたいこと]+[トリガーワード]+お願い

これで終わりです。

6. 実際の使用例4つ

非開発者もそのまま入力できる例です。

例1 — ウェブサイト作り(開発作業)

会社紹介ページとお問い合わせフォームを作って、二つがうまく連携するようにチームでお願い

一つのAIは画面を、別のAIはフォームの動作を、検収AIが「二つがうまく噛み合っているか」を点検します。

例2 — 資料調査・報告書(非開発作業)

2025年電気自動車市場トレンドを複数の資料で調査して一つに総合してエージェントチームでまとめてお願い

複数の作業者AIが分担して調査 → 検収AIが資料間の矛盾を捕捉 → チームリーダーAIが一つの報告書に統合。

例3 — 文章作成・企画(創作作業)

ファンタジー小説の世界観設定と1〜3話の筋書きを前後合わない部分なくチームビッグファイブでお願い

世界観担当と筋書き担当が「共有メモ(SMM)」を一緒に見ながら衝突を防ぎます。

例4 — 分析+検証(実務作業)

このエクセル売上データを分析して、分析が正しいか交差検証まで高性能チームで処理してお願い

分析担当と検証担当が分離され、一人で作業する時に見逃すエラーを捕捉します。

7. 動作している間何が起こっているのか(安心用)

画面に難しい言葉が流れても慌てないよう、流れを事前にお知らせします。

  1. 準備 — チームリーダーAIが目標と「完了基準」を共有メモ(SMM.md)に書きます。
  2. チーム構成 — 作業者AI複数名+検収AI1名を作ります。
  3. 協業実行 — 作業者たちが共有メモを見ながら作業し、互いに結果を渡す時「これはこう理解したということで合ってますか?」と確認します。
  4. 検収 — 検収AIが結果物同士がうまく噛み合っているか交差点検します。
  5. 総合 — チームリーダーAIがすべての結果を一つに合わせて最終版を作ります。

結果物は通常_workspace/final/というフォルダに整理されます。

8. よく詰まる部分(FAQ)

Q. 普通のClaudeアプリ(ウェブ/モバイル)でもできますか?いいえ。このハーネスはClaude Code(ターミナルツール)専用です。ウェブ・モバイルClaudeアプリでは動作しません。

Q. .claudeフォルダが見えません。.で始まるフォルダは基本的に隠されています。ファイルエクスプローラーの設定で「隠しアイテムを表示」をオンにしてください。(Mac Finder: Cmd + Shift + .)Q. トリガーワードを入れたのに普通に答えます。三つを確認してください。①.claudeとCLAUDE.mdが現在の作業フォルダ内にあるか、②そのフォルダでClaude Codeを起動したか、③トリガーワードのスペルが正確か。

Q. 毎回チームで指示した方が良いのではないですか?そうではありません。単純な作業にチームを使うと逆に遅く非効率です。「互いに噛み合う複雑な作業」にのみ使ってください。(3章参照)Q. 結果物が気に入らない場合は? そのまま続けて日本語で修正依頼すればいいです。ハーネスは各作業後にフィードバックを反映して改善されるよう設計されています。

理論的背景(もっと知りたい方へ)

このハーネスはチーム科学の古典的論文Salas, Sims & Burke (2005)、「Is there a 'Big Five' in Teamwork?」に基づいています。良いチーム成果は5つの行動(チームリーダーシップ、相互点検、バックアップ、適応性、チーム指向性)とこれを支える3つの基盤(共有精神モデル、閉ループコミュニケーション、相互信頼)から生まれるというのが骨子です。詳しい解説は原本リポジトリのdocs/TEAM-SCIENCE.mdにあります。
