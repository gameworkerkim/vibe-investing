0. 먼저 확인해야 할 것 — 공식 문서 미반영

2026-08-14 현재 DeepSeek 공식 가격 페이지는 인상 전 요율을 그대로 게시 중입니다.- 가격표 각주에 "조만간 전반적 가격 인상 계획, 인상폭 클 것으로 예상, 구체적 방안은 공식 통지에 따름"이라는문구만 존재

  • 신규 요율표·시행일·피크 시간대 모두 문서에 미게시
  • 체인지로그(Change Log) 최신 항목은 2026-07-31 (V4-Flash-0731 업데이트)
  • 단, 모델 버전은 DeepSeek-V4-Pro-0813으로 갱신 → V4-Pro 정식 출시(8/13)는 문서상 확인됨

→ 로이터 보도 수치는 개발자 문서가 아닌 별도 공식 성명 채널에서 나온 것입니다. → 인용 시 "DeepSeek 공식 성명(로이터 인용)"으로 출처를 특정하고, "공식 문서 기준"이라고 쓰면 안 됩니다.

2. 전체 요율표 (CNY / 백만 토큰)

현행가는 공식 문서 확인값. 신규가는 V4-Pro 캐시 미스·출력만 성명에 명시되었고 나머지는 "피크=한산×2" 구조와 로이터의 "+50%~+1,100%" 범위로 정합 검증된 값입니다.

입력 (캐시 미스) 3元 4.5元 9元 +200%

DeepSeek-V4-Flash

항목 현행 한산 피크 피크 인상폭
입력 (캐시 히트) 0.02元 0.05元 0.1元 +400%

출력 2元 4.5元 9元 +350%
  • 최소 인상폭: Flash 캐시 미스 한산 1 → 1.5元 = 정확히 +50% → 로이터 하한과 일치
  • 12개 셀 전부 "한산 = 피크 ÷ 2" 구조 성립

양 끝점이 오차 없이 맞아떨어지므로 이 표는 높은 신뢰도로 사용 가능합니다.

6. 요약 판단

  1. 타격 지점은 출력이 아니라 캐시. 최대 인상폭 +1,100%가 V4-Pro 캐시 히트에 집중되어 있습니다. 시스템 프롬프트·레포지토리 컨텍스트를 반복 전송하는 에이전트/RAG 워크로드는 명목 인상률보다 실질 인상률이 훨씬 큽니다. DeepSeek의 저비용 구조를 지탱하던 것이 98% 캐시 할인이었는데, 그 할인폭 자체를 축소한 것입니다.

  2. 가격 우위 유지, 격차는 급축소. V4-Pro 피크 출력 $3.92는 Claude Fable 5($50)의 약 1/13, GPT-5.6 Sol($30)의 약 1/7.7입니다. 그러나 Kimi K3($15) 대비 17배 → 3.8배, GLM 5.2($4.40) 대비 5배 → 1.1배로 좁혀졌습니다.

  3. 차등 요금제 = 캐파 제약 신호. 피크/한산 도입은 수요 분산 유인이자 추론 캐파 압박의 방증입니다. 시간대 이동 가능한 배치 워크로드는 한산 요율로 비용 절반을 회수할 수 있습니다. KST 13~15시, 19시 이후, 그리고 새벽 시간대가 회피 구간입니다.

  4. "저가 파괴자" 서사의 전환점. V4-Pro 정식 출시 당일 인상 발표는, 점유율 확보에서 단가 회수로의 전략 전환으로 읽을 수 있습니다.

  5. 공시 채널 불일치. 개발자가 참조하는 공식 가격 문서에 시행 3일 전까지 신규 요율이 게시되지 않았습니다. API 예산을 편성하는 조직 입장에서는 실무적 리스크입니다.

게재 전 검증 체크리스트

  • DeepSeek 공식 가격 페이지 갱신 여부 재확인 (현재 미반영)
  • V4-Flash 개별 요율 — 공식 고시 확인 (현재 구조 정합 기반 추정)
  • 캐시 히트 신규가 — 공식 고시 확인 (현재 +1,100% 역산 기반)
  • 신규 USD 고시가 발표 시 3장 환산표 전면 교체
  • "고처리량(high-throughput) 티어 1.5元/4.5元" 보도 — V4-Flash 한산 요율과 수치 중복. 별도 티어인지 보도 오전달인지 확인 필요
